# Adaptive AI Android app

This native Android app opens the Adaptive AI conversation interface in a WebView and provides the Android speech bridge for microphone input and spoken replies. The app no longer creates system-level or in-page floating robot overlays.

## Build and install

- Open the `android/` folder in Android Studio with JDK 17 and Android SDK 35.
- Build the app debug APK.
- Install and open Adaptive AI.
- Use the main conversation screen to type messages, use the microphone, analyze images, and hear spoken replies.

## Notes

- Microphone and camera access use Android runtime permissions.
- No API credentials or tokens are embedded in the app.
