# Roadmap

1. **Milestone 1:** FastAPI skeleton, static calculator tool, config checks, tests. (This scaffold.)
2. **Milestone 2:** One model provider adapter, chat API, request limits, server-side secret configuration.
3. **Milestone 3:** Authentication and user-controlled persistent memory.
4. **Milestone 4:** Sandboxed plugin generation and validation; no production self-modification.
5. **Milestone 5:** limited Android-native actions and user-visible permission handling.
6. **Milestone 6:** deployment hardening, monitoring, backups and recovery.
